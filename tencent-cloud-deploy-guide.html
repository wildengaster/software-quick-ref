方案概述

为什么选择腾讯云 CloudBase？
✅ 国内服务器，无需翻墙即可访问
✅ 上海/广州区域，速度快延迟低
✅ 云托管（Cloud Run）支持 Node.js 后端
✅ 有免费额度，适合学生项目
✅ 自动扩缩容，按使用量计费

推荐 方法 A：控制台部署

通过 CloudBase 网页控制台，连接 GitHub 仓库一键部署

适合：不想装命令行工具的用户

难度：⭐ 简单

高级 方法 B：CLI 部署

使用 CloudBase CLI 工具，本地命令行部署

适合：熟悉命令行的开发者

难度：⭐⭐ 中等

⚠️ 数据持久化提示：
云托管容器文件系统是临时的，容器重启后本地数据会丢失。基础内容（教程、报错方案）会从代码中的种子数据自动恢复，但用户投稿和搜索记录在容器重启后会丢失。
如需持久化，可后续升级接入 CloudBase 云数据库（详见 FAQ）。

方法 A：控制台一键部署 推荐

1 注册腾讯云账号

访问 腾讯云注册页面，使用微信扫码或手机号注册。

注册完成后，完成实名认证（学生可使用学生认证获取更多优惠）。

💡 学生用户推荐完成「腾讯云学生认证」，可获得免费云服务器等资源。
2 创建 CloudBase 环境

1. 进入 CloudBase 控制台

2. 点击「新建环境」

3. 填写环境名称，如：quick-ref

4. 选择套餐：选择「按量付费」（有免费额度）

5. 选择地域：上海 或 广州（国内访问最快）

6. 点击「确定」创建环境

按量付费套餐的免费额度包含：5万次/月调用、1GB/月流量、500次/月云函数调用。对于学生项目绰绰有余。
3 开通云托管服务

1. 在 CloudBase 控制台左侧菜单，找到「云托管」

2. 点击「开通」云托管服务

3. 选择地域（与环境一致：上海或广州）

4. 开通完成后，进入云托管管理页面

4 创建服务并部署

1. 在云托管页面，点击「新建服务」

2. 服务名称：software-quick-ref

3. 选择「代码部署」方式

4. 代码来源：选择「GitHub」

5. 如果是第一次使用，需要点击「授权」绑定 GitHub 账号

6. 选择仓库：wildengaster/software-quick-ref

7. 分支选择：main

8. 配置参数：

监听端口：3000
CPU：0.5核（最小规格即可）
内存：0.5GB（最小规格即可）
最小实例：0（无请求时自动缩为0，省钱）
最大实例：3
环境变量：NODE_ENV = production

9. 点击「部署」，等待构建完成（约 2-5 分钟）

💡 设置最小实例为 0 可以在无请求时不运行容器，大幅节省费用。冷启动约需 5-10 秒。
5 获取访问地址

部署成功后，CloudBase 会自动分配一个访问域名，格式类似：

https://quick-ref-xxxxx.sh.run.tcloudbase.com

你也可以在服务设置中绑定自定义域名。

🎉 现在可以直接在浏览器访问这个地址，国内无需翻墙！

方法 B：CLI 命令行部署 高级

1 安装 CloudBase CLI 
npm install -g @cloudbase/cli

验证安装：

tcb -v
2 登录腾讯云 
tcb login

在浏览器中完成授权后返回终端。

3 创建 cloudbaserc.json

项目根目录已包含 container.config.json，CLI 部署还需创建 cloudbaserc.json：

{
  "envId": "你的环境ID",
  "version": "2.0",
  "$schema": "https://framework-1258016615.tcloudbase.com/schema/latest.json",
  "framework": {
    "name": "software-quick-ref",
    "plugins": {
      "container": {
        "use": "@cloudbase/container-framework",
        "inputs": {
          "serviceName": "software-quick-ref",
          "containerConfig": {
            "port": 3000,
            "cpu": 0.5,
            "mem": 0.5,
            "minNum": 0,
            "maxNum": 3,
            "envVariables": {
              "NODE_ENV": "production"
            }
          },
          "codeDetail": {
            "codeType": "git",
            "gitUrl": "https://github.com/wildengaster/software-quick-ref",
            "gitBranch": "main"
          }
        }
      }
    }
  }
}

将 envId 替换为你在步骤 2 创建的环境 ID。

4 执行部署 
tcb framework deploy

等待部署完成，CLI 会输出访问地址。

方法 C：Docker 镜像部署 高级

此方法需要先构建 Docker 镜像并推送到腾讯云容器镜像服务（TCR），适合需要自定义构建流程的场景。
1 构建并推送 Docker 镜像 
# 在项目目录下构建镜像
docker build -t ccr.ccs.tencentyun.com/quick-ref/software-quick-ref:latest .

# 推送到腾讯云容器镜像服务
docker push ccr.ccs.tencentyun.com/quick-ref/software-quick-ref:latest

需要先在 腾讯云 TCR 控制台 创建命名空间和镜像仓库。

2 在云托管中创建服务

在云托管控制台选择「镜像部署」，填入镜像地址和配置参数（端口 3000，CPU 0.5核，内存 0.5GB）。

验证部署结果

✓ 部署成功后检查

1. 访问分配的域名，检查首页是否正常显示

2. 测试搜索功能：https://你的域名/api/search?q=python

3. 测试管理后台：https://你的域名/admin.html

4. 用管理员账号登录：admin / admin123

5. 检查 API 是否响应：

# 获取软件分类
curl https://你的域名/api/software

# 获取教程列表
curl https://你的域名/api/tutorials

# 获取报错方案
curl https://你的域名/api/errors

常见问题

Q: 需要付费吗？

A: 按量付费套餐有免费额度。云托管按 CPU/内存使用时长计费，设置最小实例为 0 后，无请求时不收费。学生项目月费用通常在 0-5 元。

Q: 数据会丢失吗？

A: 云托管容器文件系统是临时的，容器重启后本地文件变更会丢失。但基础数据（教程、报错方案）已在代码中作为种子数据，重启后自动恢复。仅用户投稿和搜索记录会丢失。

如需数据持久化，可接入 CloudBase 云数据库：
1. 在控制台开通「数据库」服务
2. 将 db.js 中的 JSON 操作替换为云数据库 SDK 操作
3. 数据将永久保存在云数据库中，不受容器重启影响
Q: 冷启动太慢怎么办？

A: 设置最小实例为 0 时，首次请求需要冷启动（约 5-10 秒）。如果希望更快的响应，可将最小实例设为 1（保持一个常驻实例），但会产生持续费用。

Q: 如何绑定自定义域名？

A: 在云托管服务设置中，点击「自定义域名」，添加你的域名并配置 DNS 解析指向 CloudBase 提供的 CNAME 地址。域名需要已备案。

Q: 如何更新部署？

A: 推送代码到 GitHub main 分支后，在云托管控制台点击「部署」→「重新部署」，或设置自动部署（每次 push 自动触发）。

Q: 之前在 Render 的部署还需要保留吗？

A: Render 部署可作为海外访问的备用。如果你只关注国内用户，可以删除 Render 的部署。两个平台可以同时运行，互不影响。

Q: 访问速度慢怎么办？

A: 确保选择了上海或广州地域。如果仍然慢，可以搭配腾讯云 CDN 加速：在控制台开通 CDN，将域名接入 CDN 加速。

部署后管理

🔧 日常管理操作

查看运行状态：CloudBase 控制台 → 云托管 → 选择服务 → 查看实例状态和日志

查看访问日志：服务详情 → 日志面板 → 查看实时请求日志

修改配置：服务设置 → 修改 CPU/内存/实例数等参数 → 保存并重新部署

停止服务：服务详情 → 点击「停止」（停止后不再产生费用）
