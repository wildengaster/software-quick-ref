部署步骤 推荐 免费

1 注册 Netlify 账号

访问 Netlify 注册页面

推荐使用 GitHub 账号直接登录，这样后续部署时自动关联仓库。

2 创建新站点

登录后，点击 「Add new site」 → 「Import an existing project」

选择 「Deploy with GitHub」

如果是首次使用，需要授权 Netlify 访问你的 GitHub 账号

3 选择仓库

在仓库列表中找到并选择 wildengaster/software-quick-ref

如果列表中没有显示，点击「Configure Netlify on GitHub」授权更多仓库

4 配置部署参数

Netlify 会自动检测到 netlify.toml 配置文件，大部分参数会自动填好。

确认以下配置（如果自动检测有误，手动修改）：

Owner:         wildengaster
Branch:        main
Build command: npm install
Publish dir:   .
Functions dir:  netlify/functions
💡 关键：netlify.toml 已包含所有配置，一般无需手动修改。只需确认分支是 main 即可。
5 点击部署

点击 「Deploy site」 按钮，等待部署完成（约 1-3 分钟）

部署完成后，Netlify 会分配一个随机域名，格式如：random-name-12345.netlify.app

6 验证网站

访问分配的域名，检查：

✅ 首页是否正常显示（软件卡片、教程列表）

✅ 搜索功能：在搜索框输入关键词

✅ 后台管理：访问 /admin.html，用 admin / admin123 登录

✅ API 响应：访问 /api/software 看是否返回 JSON 数据

7 自定义域名（可选）

在 Netlify 控制台 → Site settings → Domain management → Add custom domain

输入你的域名，按提示配置 DNS 解析（CNAME 指向 Netlify）

⚠️ 自定义域名需已备案才能在国内正常访问。

架构说明

Netlify 部署架构：
📁 静态文件（index.html, styles.css, script.js, admin.html 等）→ Netlify 全球 CDN
⚡ API 接口（/api/*）→ Netlify Serverless Function（通过 serverless-http 包装 Express）
💾 数据存储 → JSON 内存缓存（基础内容从代码种子数据恢复）
🔀 URL 路由 → netlify.toml 重定向规则将 /api/* → /.netlify/functions/api/*
⚠️ 数据持久化说明：
Netlify Serverless Functions 是无状态的，每次请求可能是新的函数实例。
基础内容（6个软件分类、18个教程、12个报错方案）从代码中的种子数据自动恢复，永久可用。
动态数据（用户投稿、搜索记录、管理员编辑）在函数实例生命周期内有效，
但冷启动后会重置。对展示型项目完全足够，如需持久化可后续接入 Netlify Blobs 或外部数据库。

常见问题

Q: 国内访问需要翻墙吗？

A: 大概率不需要。Netlify 使用全球 CDN（含亚洲节点），国内大部分地区可直接访问。少数地区可能偶尔慢，但不会完全无法访问。

Q: 完全免费吗？

A: Netlify 免费套餐：100GB 带宽/月 + 125万次函数调用/月 + 300分钟构建时长/月。学生项目完全够用，0费用。

Q: 如何更新网站？

A: 推送代码到 GitHub main 分支，Netlify 自动检测并重新部署。无需手动操作。

Q: 管理员登录后编辑内容会保存吗？

A: 在当前函数实例运行期间会保存（同一热启动期间多次请求共享内存）。但函数冷启动后，编辑内容会重置为种子数据。建议将核心内容写在 db.js 的种子数据中。

Q: 部署失败了怎么办？

A: 在 Netlify 控制台查看 Deploys → 点击失败的部署 → 查看 Build Log。常见原因：依赖安装失败、函数配置错误等。也可以尝试手动触发重新部署。
